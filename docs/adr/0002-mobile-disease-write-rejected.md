# 0002 — ثبت پروندهٔ بیماری از اپ موبایل انجام نمی‌شود

- **وضعیت:** فعال
- **تاریخ:** 2026-10-30

## زمینه

CRUD پروندهٔ بیماری در وب‌UI کامل است. API بیماری عمداً فقط سه endpoint تجمیعیِ
read-only و PII-free دارد — `GET /api/gis/diseases`، `GET /api/gis/disease-stats` و
`GET /api/gis/disease-map` (`routes/api.php:271-275`) — که زیر گیت `gis:read` و
`role_or_permission:map|bw` قرار دارند و به `manage_diseases` نیازی ندارند.
هیچ endpoint نوشتنیِ بیماری در API وجود ندارد.

## تصمیم

فعلاً هیچ endpoint نوشتنِ بیماری در API ساخته نمی‌شود.

## پیامدها

- اپ موبایل فقط خواندنِ تجمیعی بیماری‌ها را دارد.
- پیشنهادهای «ثبت پروندهٔ بیماری از موبایل» تا بازبینیِ دوباره مطرح نمی‌شوند.

## شرایط بازبینی

بازبینی این تصمیم به سه شرط هم‌زمان وابسته است:

1. نیاز میدانیِ مستند.
2. طرحِ PII-free — بدون برگرداندن شناسه‌ها.
3. رعایت قیدهای Discussion #1233: گسترش deny-listهای PII نه دور زدنِ آن‌ها؛ بدون فیلد
   Patient city؛ scope صریح.
