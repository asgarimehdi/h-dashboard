# فصل ۷: گزارش‌گیری و آنالیتیکس (Reports)

## مروری کلی

ماژول گزارش برای تحلیل داده‌ها، آمار و تولید گزارش‌های مدیریتی طراحی شده. تمام گزارش‌ها بر اساس **واحد سازمانی فعال** و محدودیت‌های دسترسی فیلتر می‌شوند.

---

| صفحه | مسیر | کاربرد |
|------|------|--------|
| **گزارش واحدها** | `/reports/units` | آمار واحدها، پرسنل، سخت‌افزار، تیکت |
| **گزارش پرسنل** | `/reports/persons` | تفکیک پرسنل بر اساس سمت، تحصیلات، استخدام |
| **گزارش تیکت‌ها** | `/reports/tickets` | آمار تیکت‌ها بر اساس وضعیت، اولویت، واحد، زمان |
| **گزارش کارها (Todos)** | `/reports/todos` | آمار وظایف، تکمیل، دیرکرد |
| **گزارش پیشرفته** | `/reports/advanced` | کوئری‌های سفارشی، نمودارهای ترکیبی |

## گزارش تیکت‌ها (`/reports/tickets`)

### نمای کلی
تحلیل عملکرد سیستم پشتیبانی و تیکتینگ.

### KPIها (شاخص‌های کلیدی)
| KPI | فرمول | هدف |
|-----|-------|------|
| **زمان اول پاسخ (FRT)** | میانگین زمان از ایجاد تا اولین نظر | < ۲ ساعت |
| **زمان حل (RT)** | میانگین زمان از ایجاد تا بسته شدن | < ۲۴ ساعت |
| **نرخ حل در اولین تماس (FCR)** | تیکت‌های حل شده بدون ارجاع مجدد / کل | > ۷۰٪ |
| **SLA Compliance** | تیکت‌های حل شده در مهلت / کل | > ۹۰٪ |

### نمودارها
| نمودار | توضیح |
|-------|-------|
| **تیکت بر اساس وضعیت** | Stacked bar: باز، پذیرفته، تکمیل، بسته |
| **تیکت بر اساس اولویت** | Pie: فوری، بالا، متوسط، معمولی، پایین |
| **روند زمانی** | Line: تیکت‌های ایجاد/بسته شده در ماه |
| **عملکرد واحدها** | Bar: واحدهای برتر/ضعیف در حل تیکت |
| **بار کاری مسئولان** | Bar: تعداد تیکت برای هر مسئول |

## گزارش پیشرفته (`/reports/advanced`)

### کوئری ساز (Query Builder)
برای کاربران پیشرفته و مدیران تحلیلی.

### قابلیت‌ها
1. **انتخاب موجودیت:** Hardware, Person, Ticket, Todo, Unit
2. **فیلدها:** انتخاب ستون‌های مورد نظر
3. **فیلترها:** شرط‌های WHERE (AND/OR)
4. **گروه‌بندی (Group By):** ستون برای تجمع
5. **تجمع (Aggregation):** COUNT, SUM, AVG, MIN, MAX
6. **مرتب‌سازی:** بر اساس ستون، صعودی/نزولی
7. **محدودیت (Limit):** تعداد رکوردها

### خروجی
- **جدول** — قابل مرتب‌سازی، صفحه‌بندی
- **نمودار** — Bar, Line, Pie, Area (بر اساس داده‌ها)
- **صادرات** — CSV, Excel, JSON

### مثال کوئری
```
Entity: Hardware
Fields: type, os, COUNT(*) as count
Filters: shutdown = false AND created_at > '2024-01-01'
Group By: type, os
Order By: count DESC
Limit: 20
```

## گزارش‌های زمان‌بندی (Scheduled Reports)

> **نکته:** نیاز به مجوز `manage_scheduled_reports`

### تنظیم
1. گزارش پیشرفته را بسازید
2. دکمه **«زمان‌بندی»** را بزنید
3. تنظیمات:
   - **دوره:** روزانه / هفتگی / ماهانه
   - **زمان:** ساعت خاص (UTC)
   - **گیرندگان:** لیست ایمیل‌ها
   - **فرمت:** CSV / Excel / PDF
   - **شرط:** فقط اگر داده وجود دارد / همیشه ارسال

### مدیریت
- لیست گزارش‌های زمان‌بندی
- ویرایش / غیرفعال / حذف
- تاریخچه ارسال‌ها (موفق / ناموفق)

## نکات مهم و ترفندها

| ترفند | توضیح |
|------|-------|
| **نمودار تعاملی** | هاور روی بخش‌ها → مقدار دقیق، کلیک برای دریل-داین |
| **فیلتر سریع** | در هدر جدول، آیکن قمع برای فیلتر آنی |
| **مقایسه دوره‌ای** | دو گزارش با بازه‌های مختلف در تب‌های جداگانه |
| **داشبورد شخصی** | پین کردن گزارش‌های پرکاربرد در داشبورد اصلی |
| **کلید میانبر** | `R` در صفحات گزارش برای رفرش داده‌ها |

## عیب‌یابی رایج

| مشکل | راهکار |
|-------|--------|
| گزارش خالی است | واحد سازمانی، فیلترها، بازه زمانی |
| نمودار رسم نمی‌شود | داده‌های عددی وجود دارند؟ Group By درست است؟ |
| صادرات Excel خراب است | کاراکترهای خاص در داده‌ها (trim/clean) |
| گزارش زمان‌بندی ارسال نشد | لاگ فعالیت، ایمیل گیرنده، کپچا ایمیل |
| کندی در گزارش پیشرفته | Limit بگذارید، Index وجود دارد؟ |
