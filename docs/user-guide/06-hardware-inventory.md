# فصل ۶: انبار سخت‌افزار (Hardware Inventory)

## مروری کلی

ماژول سخت‌افزار برای مدیریت کامل موجودی تجهیزات IT: پی‌سی، لپ‌تاپ، سرور، قطعات، تجهیزات شبکه و پرینترها.

---

## صفحات سخت‌افزار

| صفحه | مسیر | کاربرد |
|------|------|--------|
| **لیست دستگاه‌ها** | `/hardware` | جستجو، فیلتر، عملیات گروهی |
| **چت هوش مصنوعی** | `/hardware/ai` | پرسش از داده‌ها با زبان طبیعی |

## لیست دستگاه‌ها (`/hardware`)

### نوار ابزار بالا
- **جستجوی سراسری** — در تمام فیلدها (نام، IP، MAC، CPU، RAM، ...)
- **فیلترهای سریع (یک کلیک):**
  - 💻 لپ‌تاپ‌ها
  - 🖥️ سرورها
  - 💾 رم ۱۶GB+
  - ⚡ فقط SSD
  - ⬛ خاموش‌ها
  - ⚑ علامت‌دارها
- **فیلترهای پیشرفته** (پنل کناری):
  - نوع، OS، CPU، RAM، HDD/SSD
  - وضعیت روشن/خاموش، نوع شبکه، علامت
  - پرسنل مالک، واحد، سمت
- **ستون‌ها** — انتخاب نمایش/مخفی
- **خروجی CSV** — دانلود با فیلترها
- **افزودن دستگاه** — دکمه ➕

## افزودن دستگاه جدید

1. دکمه **افزودن دستگاه** (➕)
2. پر کردن فرم:

| فیلد | نوع | الزامی | توضیح |
|-------|-----|--------|-------|
| پرسنل مالک | Search/Select | ✅ | جستجو با کد ملی/نام، تنها واحدهای در دسترس |
| نام دستگاه (PC Name) | Text | ✅ | منحصر به فرد در محدوده دسترسی |
| نوع | Select | ✅ | Desktop / Laptop / Server / Printer / Network / Other |
| OS | Text | ❌ | Windows 10, Ubuntu 22.04, ... |
| IP معتبر | Text | ❌ | IP عمومی (در صورت داشتن) |
| IP محلی | Text | ❌ | 192.168.x.x / 10.x.x.x |
| MAC Address | Text | ❌ | ۱۲ کاراکتر هگز (AA:BB:CC:DD:EE:FF) |
| نوع شبکه | Select | ❌ | LAN / WAN / WiFi / VPN |
| سوئیچ | Text | ❌ | نام/کد سوئیچ متصل |
| پورت | Text | ❌ | شماره پورت سوئیچ |
| وضعیت خاموش | Checkbox | ❌ | پیش‌فرض: روشن |
| VLAN | Text | ❌ | شماره VLAN |
| مادربرد | Text | ❌ | مدل مادربرد |
| CPU | Text | ❌ | مثال: Intel i7-12700 |
| RAM | Text | ❌ | مثال: 32 GB DDR4 |
| HDD/SSD | Text | ❌ | مثال: 512 GB NVMe / 1 TB HDD |
| یادداشت‌ها | Textarea | ❌ | توضیحات 자유 |
| علامت‌گذاری | Checkbox | ❌ | برای اشاره ویژه |
| تاریخ آخرین نظافت | Date | ❌ | برای برنامه‌ریزی نگهداری |

3. **ذخیره** → دستگاه به لیست اضافه می‌شود

---

## ویرایش دستگاه

1. آیکن **ویرایش** (✏️) در ستون عملیات
2. تغییر فیلدهای مورد نظر
3. **به‌روزرسانی**

💡 **Partial Update** — فقط فیلدهای تغییر یافته ارسال می‌شوند.

---

## حذف دستگاه

1. آیکن **حذف** (🗑️) → مودال تأیید
2. تایید → حذف دستگاه

⚠️ **غیرقابل بازگشت**

---

## عملیات گروهی (Bulk Actions)

1. چک‌باکس ردیف‌ها (یا «انتخاب همه» در هدر)
2. دکمه‌های عملیات گروهی:
   - **علامت‌گذاری** — تمام انتخاب‌ها علامتدار می‌شوند
   - **برداشتن علامت** — علامت برداشته می‌شود
   - **حذف گروهی** — حذف تمام انتخاب‌ها (با تأیید)

## ایمپورت از اکسل (`/hardware/import`)

### مراحل دو مرحله‌ای

#### مرحله ۱: پیش‌نمایش (Preview)
1. فایل .xlsx، .xls یا .csv (ماکس ۱۰MB) را آپلود کنید
2. **کلید تطابق** را انتخاب کنید:
   - **نام دستگاه (PC Name)** — مقایسه بر اساس نام
   - **MAC Address** — مقایسه بر اساس MAC
   - **هر دو** — هر دو باید مطابقت داشته باشند
3. دکمه **«پیش‌نمایش تغییرات»**
4. جدول پیش‌نمایش با وضعیت هر ردیف:
   - 🟢 **ایجاد جدید** — دستگاه جدید
   - 🔵 **بروزرسانی** — دستگاه موجود، داده‌ها تغییر کرده
   - ⚪ **بدون تغییر** — داده‌ها یکسان
   - 🔴 **خطا** — داده‌های نامعتبر (جزئیات در tooltip)

#### مرحله ۲: تأیید و اجرا
1. پیش‌نمایش را بررسی کنید
2. دکمه **«تأیید و اجرا»**
3. گزارش نتیجه: تعداد ایجاد، بروزرسانی، خطا

### قالب فایل اکسل
ستون‌های پیشنهادی:
```
pc_name, type, os, ip_valid, ip_local, mac, net_type, switch, port, shutdown, vlan, motherboard, cpu, ram, hdd, comments, mark, clean_at, n_code
```

> 💡 فایل نمونه قابل دانلود در صفحه ایمپورت.

## چت هوش مصنوعی (`/hardware/ai`)

### قابلیت‌ها
- پرسش از داده‌های سخت‌افزار با زبان طبیعی (فارسی/انگلیسی)
- نمایش نتایج در جدول، نمودار یا متن
- تاریخچه چت (باقی می‌ماند بعد از رفرش)

### مثال پرسش‌ها
```
"تمام لپ‌تاپ‌های با رم ۱۶ گیگابایت را نشان بده"
"تعداد سرورها در واحد فناوری اطلاعات"
"دستگاه‌هایی که خاموش هستند و MAC دارند"
"خروجی CSV تمام دستگاه‌های Dell"
"آمار دستگاه‌ها بر اساس نوع و OS"
```

### دکمه‌های عملیات سریع
- 📊 آمار کلی
- 💻 لیست لپ‌تاپ‌ها
- 🖥️ لیست سرورها
- ⬛ دستگاه‌های خاموش
- 📥 خروجی CSV

## نکات مهم و ترفندها

| ترفند | توضیح |
|------|-------|
| **جستجوی MAC** | تایپ بخشی از MAC (مثال: `AA:BB`) |
| **فیلتر ترکیبی** | چند فیلتر همزمان: Type=Laptop + RAM=16GB |
| **مرتب‌سازی چندستونی** | Shift+کلیک روی ستون‌ها |
| **کپی MAC/IP** | کلیک روی مقدار در جدول → کپی |
| **کلید میانبر** | `Alt+H` برای سخت‌افزار جدید |

## عیب‌یابی رایج

| مشکل | راهکار |
|-------|--------|
| دستگاه در لیست نیست | واحد سازمانی/فیلترها را چک کنید |
| خطای MAC تکراری | MAC باید منحصر به فرد باشد |
| ایمپورت خطا می‌دهد | قالب فایل، encoding (UTF-8)، ستون‌ها |
| چت AI کار نمی‌کند | OPENAI_API_KEY در .env تنظیم نشده |
| پرسنل در لیست مالک نیست | پرسنل باید در واحدهای در دسترس شما باشد |
