# فصل ۸: نظارت بر شبکه و IT Monitoring

## مروری کلی

ماژول نظارت IT برای مانیتورینگ لحظه‌ای شبکه، سوئیچ‌ها، وایرلس، پهنای باند و وضعیت دستگاه‌های شبکه‌ای.

## صفحات نظارت IT

| صفحه | مسیر | کاربرد |
|------|------|--------|
| **شبکه‌ها** | `/it/networks` | نظارت بر سوئیچ‌ها، پورت‌ها، ترافیک |
| **وایرلس** | `/it/wireless` | نقاط دسترسی، قدرت سیگنال، کاربران |

## شبکه‌ها (`/it/networks`)

### داشبورد شبکه
- **وضعیت کلی:** همه سوئیچ‌ها در دسترس / برخی قطعی / همه قطع
- **پهنای باند کل:** Upload / Download
- **بازدهی:** % استفاده از پهنای باند

![داشبورد شبکه](screenshots/08-it-networks.png)
*نمونه داشبورد نظارت شبکه*

### جدول سوئیچ‌ها
| نام سوئیچ | IP | مدل | پورت‌های فعال | ترافیک (RX/TX) | وضعیت | آخرین بروز رسانی |

### نظارت بر پورت
- کلیک روی سوئیچ → نمایش همه پورت‌ها
- وضعیت هر پورت: فعال/خاموش/متصل/قطع
- دستگاه متصل (اگر شناخته شده باشد)

### هشدارها (Alerts)
| سطح | شرط | اقدام پیشنهادی |
|------|------|--------------|
| 🔴 بحرانی | سوئیچ قطع شده | بررسی فیزیکی، ریستارت |
| 🟡 هشدار | پورت > ۸۰% استفاده | بررسی بارگذاری |
| 🟢 نرمال | تمام پورت‌ها سالم | — |

## وایرلس (`/it/wireless`)

### داشبورد وایرلس
- **تعداد کل AP (Access Point)**
- **APهای فعال / غیرفعال**
- **کاربران متصل**
- **میانگین قدرت سیگنال (RSSI)**

### جدول نقاط دسترسی
| نام AP | MAC | مکان | کانال | قدرت سیگنال | کاربران متصل | بار (%) | وضعیت |

### تحلیل سیگنال
- **نقشه حرارتی (Heatmap)** — توزیع قدرت سیگنال در محیط
- **پووشش (Coverage)** — درصد ناحیه‌ای که سیگنال > -۷۰dBm

### هشدارهای وایرلس
| هشدار | شرط | اقدام |
|--------|------|------|
| AP غیرفعال | بیش از ۵ دقیقه بدون ارتباط | بررسی فیزیکی AP |
| سیگنال ضعیف | RSSI < -۸۰dBm در نقاط مهم | افزودن AP یا تنظیم کانال |
| بار زیاد | > ۸۰% در AP | تنظیم load balancing |
| کانال هم‌پوشانی | کانال‌های مجاور استفاده می‌شوند | تغییر کانال |

## ترافیک و Zabbix

### یکپارچه‌سازی Zabbix
- **API Zabbix** برای جمع‌آوری متریک‌های لحظه‌ای
- متریک‌های قابل نظارت:
  - ترافیک شبکه (bps در هر پورت)
  - CPU / RAM سوئیچ
  - دما، ولتاژ
  - تعداد MAC یادگرفته شده

### APIهای موجود
| متد | مسیر | توصیف |
|------|------|------|
| GET | `/api/zabbix/traffic` | ترافیک لحظه‌ای سوئیچ‌ها |
| GET | `/api/zabbix/multi-latest` | مقادیر چندین آیتم همزمان |

## عیب‌یابی رایج

| مشکل | راهکار |
|-------|--------|
| داده لود نمی‌شود | Zabbix API در دسترس نیست، تنظیمات را چک کنید |
| وضعیت همه قطع است | بررسی اتصال شبکه، سرویس Zabbix |
| هشدار نمی‌رسد | تنظیمات اعلان در پروفایل |
| مقادیر صفر | سوئیچ/AP جدید، هنوز متریک ندارد |
| تأخیر در داده | Zabbix polling interval (پیش‌فرض ۶۰ ثانیه) |
