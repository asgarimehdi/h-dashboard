# فصل ۴: بلیطینگ و پشتیبانی (Tickets)

## مروری کلی

سیستم بلیطینگ برای مدیریت درخواست‌ها، گزارش خرابی، پیشنهادات و وظایف پشتیبانی IT و عملیاتی طراحی شده است.

---

## منوهای زیرشاخه

از منوی کناری **بلیطینگ** کلیک کنید:

| زیرمنو | آدرس | کاربرد |
|--------|-------|--------|
| **صندوق ورودی** | `/tickets/inbox` | تیکت‌های به شما تخصیص یافته |
| **نظارت** | `/tickets/monitoring` | تمام تیکت‌های واحد شما |
| **ایجاد تیکت** | `/tickets/create` | ثبت درخواست جدید |
| **آرشیو** | `/tickets/archive` | تیکت‌های بسته/تکمیل شده |

---

## ایجاد تیکت جدید

**مسیر:** `/tickets/create`

### فرم ایجاد تیکت

| فیلد | نوع | الزامی | توضیح |
|-------|-----|--------|-------|
| موضوع | Text | ✅ | عنوان خلاصه (حداکثر ۱۰۰ کاراکتر) |
| توضیحات | Textarea | ✅ | جزئیات کامل مشکل/درخواست |
| اولویت | Select | ✅ | فوری / بالا / متوسط / معمولی / پایین |
| واحد مقصد | Select | ✅ | واحد سازمانی مرتبط (پیش‌فرض: واحد فعال) |
| فایل پیوست | File | ❌ | اسکرین‌شات، لاگ، سند (ماکس ۱۰MB) |

### پس از ثبت
- تیکت با وضعیت **باز** و اولویت انتخابی ثبت می‌شود
- ایمیل به **واحد مقصد** ارسال می‌شود
- در **نظارت** واحد مقصد قابل مشاهده است

---

## گردش کار وضعیت (Workflow)

```
باز (Open)
    │
    ├──► پذیرفته شده (Accepted) ──► تکمیل شده (Completed) ──► بسته (Closed)
    │                                    │
    │                                    └──► باز شده مجدد (Reopened)
    │
    └──► رد شده (Rejected) ──► بسته (Closed)
```

### قوانین
| عمل | مجوز لازم | شرط |
|------|-----------|-----|
| **پذیرش** | مسئول (Assignee) | وضعیت باز |
| **تکمیل** | مسئول | وضعیت پذیرفته شده |
| **بستن** | مدیر واحد | هر وضعیتی |
| **باز کردن مجدد** | هر کسی | وضعیت بسته/رد شده |
| **تخصیص مجدد** | مدیر واحد | هر وضعیتی |
| **حذف** | مدیر سیستم | هر وضعیتی |

## صندوق ورودی (Inbox)

**مسیر:** `/tickets/inbox`

نمایش تیکت‌هایی که به شما (کاربر فعلی) تخصیص یافته‌اند.

### فیلترها
- **وضعیت:** همه / باز / پذیرفته شده / تکمیل شده / رد شده / بسته
- **اولویت:** همه / فوری / بالا / متوسط / معمولی / پایین

### ستون‌ها
| موضوع | اولویت | وضعیت | واحد | مسئول | تاریخ ایجاد | عملیات |

### عملیات روی هر تیکت
- **مشاهده** — جزئیات کامل، نظرات، پیوست‌ها
- **پذیرش** — تغییر وضعیت به «پذیرفته شده» (دکمه در صفحه جزئیات)
- **تکمیل** — نهایی‌سازی (دکمه در صفحه جزئیات، نیاز به وضعیت پذیرفته شده)
- **نظر دادن** — افزودن نظر در تیکت

---

## نظارت (Monitoring)

**مسیر:** `/tickets/monitoring`

نمایش **تمام تیکت‌های واحد شما** — نه فقط تیکت‌های شخصی.

### قابلیت‌های اضافی
- **آمار کلی:** تعداد کل، باز، پذیرفته شده، تکمیل شده، بسته
- **فیلتر واحد فرزند:** نمایش تیکت‌های زیرمجموعه‌ها
- **تخصیص گروهی:** انتخاب چند تیکت → تخصیص به یک پرسنل
- **تغییر وضعیت گروهی:** بستن یا پذیرش دسته‌ای

### جدول نظارت
ستون‌های اضافی نسبت به Inbox:
- **ایجادکننده** — نام کاربری که تیکت را ثبت کرده
- **مسئول** — شخصی که تیکت به او تخصیص یافته

## جزئیات تیکت

**مسیر:** `/tickets/{id}`

### بخش‌ها
1. **هدر** — موضوع، وضعیت، اولویت، واحد، تاریخ‌ها
2. **اطلاعات اصلی** — توضیحات کامل، فایل‌های پیوست
3. **نظرات** — تمام نظرات کاربران (با تاریخ و نام)
4. **فعالیت‌ها (Activity Log)** — تاریخچه تمام عملیات (ایجاد، تخصیص، وضعیت، نظر)
5. **عملیات** — پذیرش، تکمیل، تخصیص مجدد، بستن، حذف

### افزودن نظر
1. در بخش نظرات، متن را وارد کنید
2. (اختیاری) فایل پیوست اضافه کنید
3. **ارسال نظر**

> همه کاربران مرتبط (ایجادکننده، مسئول، مدیر واحد) از نظر جدید مطلع می‌شوند.

---

## اولویت‌بندی تیکت‌ها

| اولویت | رنگ | زمان هدف | کاربرد |
|--------|-----|----------|--------|
| **فوری (Urgent)** | 🔴 قرمز | < ۱ ساعت | قطعی سیستم، مرگ و میر، بحران امنیتی |
| **بالا (High)** | 🟠 نارنجی | < ۴ ساعت | خرابی سخت‌افزار مهم، عدم دسترسی حیاتی |
| **متوسط (Medium)** | 🟡 زرد | < ۲۴ ساعت | مشکل عملکردی، درخواست تغییر |
| **معمولی (Normal)** | 🟢 سبز | < ۳ روز | گزارش روتین، پرسش عمومی |
| **پایین (Low)** | 🔵 آبی | < ۷ روز | پیشنهاد، مستندات، غیرفوری |

⚠️ **هشدار:** استفاده نادرست از «فوری» باعث کاهش حساسیت تیم می‌شود.

---

## عملیات گروهی

در نمای **نظارت**:
1. چک‌باکس‌های تیکت‌های مورد نظر را بزنید
2. از منوی عملیات گروهی:
   - **تخصیص به** — انتخاب یک پرسنل
   - **تغییر وضعیت** — بستن/پذیرش دسته‌ای
   - **تغییر اولویت** — یکنواخت کردن اولویت‌ها
   - **خروجی اکسل** — دانلود لیست

## آرشیو تیکت‌ها

**مسیر:** `/tickets/archive`

تیکت‌های بسته/تکمیل شده. امکان جستجو و فیلتر بر اساس:
- تاریخ بسته شدن
- واحد
- مسئول
- اولویت

## نکات مهم و ترفندها

| ترفند | توضیح |
|------|-------|
| **اعلان ایمیل** | برای تیکت جدید، تغییر وضعیت، نظر جدید |
| **جستجو** | موضوع، توضیحات، شماره تیکت، نام کاربر |
| **پیوست** | pdf, jpg, png, txt, log, xlsx — ماکس ۱۰MB |
| **کلید میانبر** | `N` برای تیکت جدید در صفحات بلیطینگ |
| **داشبورد** | آمار تیکت‌ها در داشبورد اصلی |

## عیب‌یابی رایج

| مشکل | دلیل | راهکار |
|-------|------|--------|
| تیکت ایجاد نمی‌شود | واحد مقصد معتبر نیست | واحد را از لیست انتخاب کنید |
| نمی‌توانم ببندم | وضعیت پذیرفته شده نیست | ابتدا پذیرش کنید |
| تیکت نمایش داده نمی‌شود | واحد فعال اشتباه است | واحد سازمانی را چک کنید |
| ایمیل نمی‌رسد | تنظیمات اعلان خاموش است | در پروفایل → اعلان‌ها |
| دسترسی ندارم | مجوز کافی نیست | مدیر برای `manage_tickets` تماس بگیرید |
