# فصل ۹: تنظیمات و مدیریت سیستم (Admin Settings)

## مروری کلی

تنظیمات مدیریتی برای کنترل دسترسی، مدیریت کاربران، نقش‌ها، مجوزها و نظارت بر فعالیت‌ها.

---

## صفحات تنظیمات

| صفحه | مسیر | کاربرد |
|------|------|--------|
| **کاربران** | `/settings/users` | مدیریت کاربران، رمز، وضعیت |
| **نقش‌ها** | `/settings/roles` | تعریف نقش‌ها (Admin، Manager، Operator، Viewer) |
| **مجوزها** | `/settings/permissions` | مدیریت مجوزهای دقیق |
| **پروفایل** | `/profile` | پروفایل کاربر فعلی |
| **لاگ فعالیت** | `/activity-log` | تاریخچه تمام عملیات حساس |

---

## کاربران (`/settings/users`)

### لیست کاربران
| نام کاربری | کد ملی | نام کامل | ایمیل | نقش‌ها | وضعیت | عملیات |

![لیست کاربران](screenshots/09-admin-users.png)
*نمونه لیست کاربران در تنظیمات ادمین*

### عملیات
- **افزودن کاربر** — نام کاربری، کد ملی، رمز، نقش‌ها
- **ویرایش** — تغییر نقش، رمز، وضعیت فعال/غیرفعال
- **حذف** — حذف کاربر (غیرقابل بازگشت)
- **بازنشانی رمز** — تنظیم رمز پیش‌فرض
- **خروجی اکسل** — لیست کاربران

### نکات مهم
- کد ملی باید با پرسنل همخوانی داشته باشد (برای Scoping)
- کاربران غیرفعال نمی‌توانند وارد شوند
- کاربران باید حداقل یک نقش داشته باشند

---

## نقش‌ها (`/settings/roles`)

### نقش‌های پیش‌فرض
| نقش | توضیح | مجوزهای کلیدی |
|------|-------|----------------|
| **admin** | مدیر سیستم | دسترسی کامل، مدیریت کاربران/تنظیمات |
| **manager** | مدیر واحد | گزارش‌ها، نظارت، پرسنل، سخت‌افزار واحد خود |
| **operator** | کارشناس | سخت‌افزار/تیکت/پشتیبان | سخت‌افزار، تیکت، پرسنل (محدود به واحد) |
| **viewer** | مشاهده‌کننده | فقط خواندن داشبورد و گزارش‌ها |

### مدیریت نقش‌ها
- **افزودن** — نام، توضیح، مجوزها
- **ویرایش** — تغییر مجوزها
- **حذف** — تنها اگر هیچ کاربری آن نقش را نداشته باشد

## پروفایل (`/profile`)

تنظیمات کاربر فعلی:
- **اطلاعات شخصی** — نام، ایمیل، عکس
- **رمز عبور** — تغییر رمز
- **اعلان‌ها** — ایمیل برای تیکت، گزارش، سیستم
- **زبان** — فارسی (پیش‌فرض) / انگلیسی
- **موضوع** — روشن / تیره / سیستمی
- **کلید API** — برای دسترسی برنامه‌ریزی (Sanctum token)

---

## لاگ فعالیت (`/activity-log`)

### ثبت رویدادها
تمام عملیات حساس به‌صورت خودکار لاگ می‌شوند:
- ورود/خروج
- ایجاد/ویرایش/حذف پرسنل، سخت‌افزار، تیکت
- تغییر نقش/مجوز
- ایمپورت/اکспорт
- ورود ناموفق

### فیلترها
- **کاربر** — انتخاب کاربر خاص
- **عملیات** — created, updated, deleted, login, failed_login
- **موجودیت** — Hardware, Person, Ticket, User, Role
- **بازه زمانی** — امروز، هفته، ماه، سفارشی

### خروجی
- نمایش در جدول (پیش‌نمایش ۱۰۰)
- دانلود CSV (تمام نتایج)

## محدوده دسترسی سازمانی (Scoping)

**مهم:** تمام داده‌ها بر اساس **واحد سازمانی** فیلتر می‌شوند.

### نحوه کارکرد
1. هر کاربر به یک یا چند واحد تخصیص داده می‌شود
2. کاربر به **واحد خود + تمام زیرمجموعه‌ها** دسترسی دارد
3. این محدودیت روی همه موارد اعمال می‌شود:
   - لیست پرسنل
   - لیست سخت‌افزار
   - تیکت‌ها
   - گزارش‌ها
   - نقشه‌ها

### مدیریت در تنظیمات
- در ویرایش کاربر → فیلد **واحد سازمانی** (u_id)
- برای دسترسی چند واحد: مجوز `manage_organizational_scope` (فقط ادمین)

## نکات مهم و ترفندها

| ترفند | توضیح |
|------|-------|
| **کپی توکن API** | در پروفایل → کلیک روی توکن → کپی |
| **جستجوی لاگ** | ترکیب فیلترها برای عیب‌یابی سریع |
| **نقش‌های ترکیبی** | کاربر می‌تواند چند نقش داشته باشد |
| **بازنشانی رمز انبوه** | در لیست کاربران → عملیات گروهی |
| **کلید میانبر** | `S` برای باز کردن تنظیمات |

---

## عیب‌یابی رایج

| مشکل | راهکار |
|-------|--------|
| کاربر داده‌ها را نمی‌بیند | واحد سازمانی تخصیص داده نشده |
| مجوز اعمال نمی‌شود | کش Permission — Ctrl+F5 یا logout/login |
| لاگ فعالیت خالی است | مجوز `view_activity_log` نیست |
| توکن API کار نمی‌کند | منقضی شده، مجدد تولید کنید |
| نقش حذف نمی‌شود | کاربری آن نقش را دارد، ابتدا تغییر دهید |
