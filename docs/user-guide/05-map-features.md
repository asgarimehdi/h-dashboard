# فصل ۵: ویژگی‌های نقشه (Maps)

## مروری کلی

ماژول نقشه برای نمایش جغرافیایی واحدهای سازمانی، محاسبه مسیر، تحلیل مرزها و مدیریت لایه‌های فضایی طراحی شده. با **Leaflet.js** و **OpenStreetMap** پیاده‌سازی شده.

---

## صفحات نقشه

| صفحه | مسیر | کاربرد اصلی |
|------|------|------------|
| **واحدها روی نقشه** | `/maps/units` | نمایش تمام واحدها به صورت مارکر |
| **مسیر یابی ساده** | `/maps/route` | مسیر بین دو نقطه (A → B) |
| **مسیر پیشرفته** | `/maps/route2` | مسیر با نقاط واسطه، بهینه‌سازی |
| **مرزها** | `/maps/boundaries` | نمایش پلی‌گن مرزهای واحدها |
| **نقطه** | `/maps/point` | جزئیات یک مختصات جغرافیایی |
| **شهرستان‌ها** | `/maps/counties` | نمای سطح شهرستانی |

## واحدها روی نقشه (`/maps/units`)

### نمای اصلی
- **مارکرهای رنگی** بر اساس نوع واحد (بیمارستان، مرکز درمانی، دفتر، انبار، ...)
- **خوشه‌بندی (Clustering)** برای نقاط متراکم
- **پنل کناری** با لیست، جستجو و فیلترها

![نقشه واحدها](screenshots/05-map-units.png)
*نمونه نقشه واحدهای سازمانی با مارکرها*

### کنترل‌های نقشه
| کنترل | عملکرد |
|------|--------|
| **جستجو** | نام واحد، کد واحد |
| **فیلتر نوع** | نمایش فقط نوع خاص |
| **فیلتر سطح** | استان / شهرستان / بخش / دهستان |
| **زوم + / -** | یا اسکرول ماوس |
| **تمام صفحه** | دکمه ▢ در گوشه |

### پاپ‌آپ مارکر
کلیک روی مارکر → نمایش:
- نام واحد
- نوع واحد
- مختصات (Lat, Lng)
- کد واحد
- دکمه «مشاهده جزئیات» → پروفایل واحد

---

## مسیر یابی ساده (`/maps/route`)

### مراحل محاسبه مسیر
1. **نقطه مبدأ:** کلیک روی نقشه یا انتخاب از لیست واحدها
2. **نقطه مقصد:** کلیک روی نقشه یا انتخاب از لیست واحدها
3. دکمه **«محاسبه مسیر»**
4. نمایش:
   - خط مسیر روی نقشه (آبی)
   - فاصله (کیلومتر)
   - زمان تخمینی (دقیقه)
   - دستورالعمل‌های ناوبری (Turn-by-turn)

---

## مسیر پیشرفته (`/maps/route2`)

### قابلیت‌های اضافه
- **نقاط واسطه (Waypoints):** اضافه کردن چندین توقف میانی
- **بهینه‌سازی:** سفارش بهینه نقاط برای کمترین فاصله/زمان
- **پروفایل ارتفاع:** نمودار ارتفاع مسیر
- **صادر کردن GPX/KML:** برای دستگاه‌های GPS

---

## مرزها و لایه‌های جغرافیایی

### نمایش مرز واحد (`/maps/boundaries`)
- لایه **Polygon** برای هر واحد که مرز تعریف دارد
- رنگ‌بندی بر اساس سطح واحد (استان، شهرستان، بخش، دهستان)
- شفافیت قابل تنظیم
- کلیک روی پلی‌گن → اطلاعات واحد

### لایه‌های پایه (Base Layers)
- OpenStreetMap (پیش‌فرض)
- Satellite (ماهواره‌ای)
- Topographic (تضاریسی)
- Dark Mode (شبانه)

### لایه‌های رویی (Overlays)
- مرزهای واحدها
- شبکه جاده‌ها
- نقاط کنونج (POI): بیمارستان‌ها، داروخانه‌ها، ایستگاه‌های امدادرسانی

---

## ابزارهای تحلیل فضایی

### جستجوی محوطه‌ای (Bounding Box)
1. دکمه **«انتخاب ناحیه»** (مربع نقطه‌چین)
2. کشیدن مستطیل روی نقشه
3. لیست واحدهای داخل ناحیه

### جستجوی شعاعی (Radius Search)
1. کلیک راست روی نقطه → «جستجو در شعاع»
2. وارد کردن شعاع (کیلومتر)
3. نمایش واحدهای در شعاع

### محاسبه فاصله
- ابزار سنجاق (Ruler) → دو نقطه → فاصله مستقیم (Haversine) + فاصله جاده‌ای

## داده‌های جغرافیایی

### ساختار داده واحد
```json
{
  "id": 1,
  "name": "بیمارستان امام خمینی",
  "unit_type": "بیمارستان",
  "lat": 35.6892,
  "lng": 51.3890,
  "parent_id": 5,
  "region_id": 3,
  "boundary": "POLYGON((...))"  // اختیاری
}
```

### ایمپورت داده‌های GIS
- فرمت‌های پشتیبانی: **GeoJSON**, **Shapefile** (.zip), **KML**
- از منوی **تنظیمات → ایمپورت GIS**
- بررسی تداخل مرزها (Topology validation)

## نکات مهم و ترفیدها

| نکته | توضیح |
|------|-------|
| **کلیک راست** | منوی محتوا: جستجوی شعاعی، اندازه‌گیری، کپی مختصات |
| **میانبرها** | `+`/`-` زوم، `R` روت، `M` مارکر، `Esc` انصراف |
| **موبایل** | دو انگشت برای زوم/چرخش، نگه‌داشتن برای مارکر |
| **حالت شب** | منوی لایه‌ها → Base Layer → Dark |
| **صادرات** | PNG تصویر نقشه، GeoJSON داده‌ها، PDF گزارش |

## عیب‌یابی رایج

| مشکل | راهکار |
|-------|--------|
| نقشه لود نمی‌شود | اتصال اینترنت (OpenStreetMap tiles) |
| مارکرها نمایش داده نمی‌شوند | زوم کنید، فیلترها را بررسی کنید |
| مرزها نمایش داده نمی‌شوند | واحد باید فیلد `boundary` داشته باشد |
| مسیر محاسبه نمی‌شود | مبدأ/مقصد معتبر، سرویس OSRM در دسترس باشد |
| زوم محدود است | Max zoom در تنظیمات نقشه قابل تغییر است |
