# راهنمای کاربر داشبورد سلامت (Health Dashboard)

**نسخه:** 1.0  
**تاریخ:** ۱۴۰۳/۰۵/۰۸  
**زبان:** فارسی (RTL)

---

## مقدمه

داشبورد سلامت یک سیستم جامع مدیریت موجودات سخت‌افزاری، پرسنل، تیکت‌ها، واحدهای سازمانی و گزارش‌گیری برای مراکز درمانی و بیمارستانی است. این راهنما به شما کمک می‌کند تا از تمام قابلیت‌های سیستم بهینه‌ترین استفاده را ببرید.

### پیش‌نیازها
- دسترسی به اینترنت
- مرورگر وب مدرن (Chrome، Firefox، Edge، Safari)
- نام کاربری و رمز عبور معتبر (توسط مدیر سیستم صادر شده)

## دسترسی به راهنمای سریع (In-App Help)

در تمام صفحات اصلی، یک آیکن **❓** در کنار عنوان بخش قرار دارد. کلیک بر روی آن یک مودال راهنمای مرتبط با آن بخش را باز می‌کند که شامل:
- هدف بخش
- مراحل انجام کار
- نکات مهم و ترفندها
